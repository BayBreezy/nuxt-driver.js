## Features

- **Easy Integration**: Quickly add guided tours to your Nuxt projects with minimal setup.
- **Customizable**: Tailor the appearance and behavior of tooltips to match your application's design and user experience.
- **Step-by-Step Navigation**: Guide users through workflows and features with sequential tooltips and intuitive navigation controls.
- **Rich Content Support**: Enhance guides with text, images, videos, and interactive elements.
- **Responsive Design**: Ensure a consistent experience across devices with responsive guides that adapt to different screen sizes.

## Credits ❤️

This module is a wrapper around [Driver.js](https://driverjs.com/){target="_blank"}, a fantastic standalone library for creating guided tours. Check out the [Driver.js documentation](https://driverjs.com/docs/installation){target="_blank"} for in-depth details on all available options and features.
