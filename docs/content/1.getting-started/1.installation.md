## Install the package

Add the package to your project

:prose-pm-install{name="nuxt-driver.js"}
:::

:::prose-step
## Register the module

Add the module to your `nuxt.config` file

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["nuxt-driver.js"],
});
```
:::
::
