[Module options are set under the `driverJs` key in your `nuxt.config`.]{class="text-lg text-muted-foreground"}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["nuxt-driver.js"],
  driverJs: {
    storagePrefix: "my-app",
  },
});
```

## Options

### `storagePrefix`

- **Type:** `string`
- **Default:** `"nuxt-driver"`

The prefix prepended to every localStorage key used by `useDriver`. Changing this value is useful when you have multiple apps sharing the same origin and want to avoid key collisions.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["nuxt-driver.js"],
  driverJs: {
    // localStorage keys will be "acme:tour-name" instead of "nuxt-driver:tour-name"
    storagePrefix: "acme",
  },
});
```
